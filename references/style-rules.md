# 风格规则（最小编辑视角）

## 1. 什么时候才动手

只有以下四类问题值得改：

1. **硬错误**：语法/句法/搭配明确错误；
2. **一致性**：术语、缩写、大小写与全篇不一致；
3. **不可读**：长句或冗余结构导致理解成本明显升高；
4. **语域不合**：与目标体裁明显冲突（期刊 vs 学位论文 vs 基金）。

除此之外一律 `no-change`。**“可以更地道”不是修改理由。**

## 2. 保护对象（一律不动）

- 数值、单位、百分比、`p` 值、样本量、置信区间；
- 引用编号与作者-年份：`[12]`、`[3-5]`、`(Smith, 2020)`；
- 图表与章节指向：`Fig. 2`、`Table 1`、`Eq. (3)`、`§2.1`、`图 3`、`表 2`；
- 公式块（`$...$`、`$$...$$`、`\begin{equation}`）；
- 参考文献表；
- 专有名词、基因/蛋白/材料名称的标准写法（除非属于本次统一范围）。

若为了格式必须触碰这些对象，`reason` 必须写明“仅格式，未改数值/未改内容”，且 `guards` 对应项仍为 `true`。

## 3. 语域速查

| 体裁 | 应避免 | 应保持 |
|---|---|---|
| 期刊论文 | 口语化、第一人称过度、宣传化形容词 | 客观、被动与主动混用、限定词明确 |
| 学位论文 | 碎片化短句、跳跃结论 | 章节衔接、充分解释、术语稳定 |
| 基金申请 | 绝对化承诺、无据的“国际领先” | 目标可验证、风险与替代方案写清 |
| 审稿回复 | 情绪化、对抗性措辞 | 逐条对应、承认与反驳均有依据 |
| 英文摘要 | 中式直译、冗余名词化 | 一句话一个主张、强度与结论匹配 |

## 4. 常见最小编辑替换（只在确实错时使用）

| 原文 | 改后 | 类型 |
|---|---|---|
| in order to | to | clarity |
| due to the fact that | because | clarity |
| a total of 120 | 120 | clarity（数字不变） |
| utilize | use | usage |
| prior to | before | usage |
| each and every | every | clarity |
| conduct a research | conduct research | usage |

反向提醒：`due to` 与 `because of`、`while` 与 `whereas` 的替换**不属于错误修正**，除非原文用法确实错误，否则不要动。

## 5. 长句切分

只在满足全部条件时切分：句子 ≥ 45 词、包含 ≥ 3 个并列从句、切分后不改变任何限定词与否定范围。切分后必须逐段核对数值/引用仍在同一分句内，否则回退。

## 6. 不确定就标注

拿不准某句是否属于硬错误时，选择 `no-change` + 在 `uncertainty` 里写明疑点，而不是冒险改。**保留原句的代价远小于改错主张。**
