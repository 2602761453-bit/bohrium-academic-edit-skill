# 修改类型标签表

每条 `edits[].type` 只能从下表取值，可并列（如 `["grammar","terminology"]`）。标签决定评审如何理解“这处该不该改”，也是“最小编辑”承诺的可核验形式。

| 标签 | 触发条件 | 不算此标签的情况 | reason 写法示例 |
|---|---|---|---|
| `grammar` | 主谓一致、时态、语态、冠词、介词、单复数、悬垂修饰、句子成分残缺 | 只是“更地道”的措辞替换 | “主谓不一致：data … shows → data … show” |
| `usage` | 搭配错误、词义误用、中式英语搭配 | 风格偏好 | “搭配错误：conduct a research → conduct research” |
| `register` | 口语化、宣传化、绝对化、人称误用、体裁不合 | 学术性正常但句子长 | “口语化：a lot of → many” |
| `terminology` | 同一概念多种写法、缩写首现未展开、大小写/连字符漂移 | 术语本身正确但换成同义词 | “术语统一：FEV-1 → FEV1（按术语表）”；必须同时出现在 `terminology[]` |
| `clarity` | 冗余连接词、重复、超长句导致理解成本 | 修辞性长短变化 | “冗余：due to the fact that → because” |
| `format` | 标点、空格、全角半角、编号格式、引用格式 | 任何改变数值的改动 | “格式：删除重复空格；仅格式，未改数值” |
| `no-change` | 该句无需修改 | — | 必须收录，`revised` 与 `original` 相同，`reason` 可写“无硬错误，保留原句” |

## 最小编辑标记

当多处小改可合并为一次整句重写时，仍按**逐处**记录，并在 `reason` 前缀 `最小编辑：`。整句重写只有在原句确实无法局部修复时才允许，且必须在 `reason` 写明“整句重写原因：……”。

## 禁止的类型滥用

- 不为 `no-change` 的句子编造修改理由；
- 不把 `format` 当万能标签掩盖语义改动；
- 不在同一条 `edit` 里既做 `terminology` 又做 `clarity` 却只写一个理由——多理由要分行写清。
